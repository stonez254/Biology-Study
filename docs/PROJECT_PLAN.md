## Assessment rules
### RAT
- 10 questions
- 3 choices per question
- 15-minute test limit
- 5 points per correct answer

### CAT
- 20 questions
- 30-minute test limit
- 10 points per correct answer
- Scheduled every 3 days

All schedules, passmarks and point values should be configurable rather than hard-coded.
