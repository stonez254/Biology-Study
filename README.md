# Biology-Study

A modern biology and medical study platform with daily RATs, scheduled CATs, revision, analytics, gamification, and offline-safe study progress.

## Planned stack
- React + Vite
- TypeScript
- Tailwind CSS
- Local-first persistence
- Backend/API layer
- PDF export

## Core modules
- Authentication and student profile
- Dashboard
- RAT/CAT assessment engine
- Question bank
- Revision and missed-question system
- Custom practice tests
- Analytics
- Calendar and tasks
- Points, levels, streaks and badges
- Theme/accessibility settings
- PDF export
